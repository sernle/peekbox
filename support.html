Support

Questions, a file Peekbox won't open, or an idea? Email peekboxapp@outlook.com — if you can, include the archive's format and size and what you expected to happen.

Peekbox asks for access to a folder

The Mac App Store version is sandboxed, so macOS asks before it saves into a folder. Click Allow Access once and Peekbox remembers. To allow everything at once, open Help → Welcome to Peekbox → Allow… and choose your Home folder. Settings → Folder access lists and forgets these permissions.

Space-bar previews or Finder icons don't appear

Open System Settings → General → Login Items & Extensions → Quick Look and switch on Peekbox. Then press Space on an archive in Finder. Icons may take a moment to refresh.

An archive asks for a password

Type it and tick “Remember in Keychain” to have Peekbox try it automatically next time. Saved passwords can be removed in Settings.

“Some files are damaged”

Peekbox names the broken files and offers Extract Intact Files, which saves everything else. If the archive was a download, downloading it again usually fixes it.

File names look garbled

Zips made on Windows in another language store names in an old encoding. Peekbox detects this and shows a banner where you can pick the language; Fix Permanently saves a copy that opens correctly everywhere.

Split archives (.001, .part1.rar)

Keep all the parts in the same folder and open the first one.
